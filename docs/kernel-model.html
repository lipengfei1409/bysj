内核与模型

本仓库提供 RMSNorm/GIE 原生算子和融合分段算子；DPA4Model 默认用原生算子替换 GIE/RMSNorm，可选加速 attention-free SO2Convolution 的 envelope aggregation，并可用 fused= 把 segment_sum/segment_softmax 绑进 DeepMD 自己的分派接缝。DPA4/SeZM 完整 descriptor、interaction、fitting 和能量/力/virial 路径由 DeepMD-kit 实现。下方源码映射对应相邻 deepmd-kit checkout 的 DPA4 实现。

Native primitives

当前本地 HIP 扩展默认编译 RMSNorm 与 GIE；完整 SeZM descriptor/interaction/fitting 由 DeepMD-kit 管理。

DPA4 / SeZM inference

DeepMD adapter

DPA4Model → DeepPot → DeepMD → fused= (segment_sum / segment_softmax) envelope reduction

模型图、邻居图、能量和导数由 DeepMD-kit 执行；适配器默认仅将受支持的 GIE 和 plain RMSNorm 阶段替换为原生 HIP/DCU 算子；SO(2) 的 destination envelope reduction 由 fused=("envelope",) 的 segment_sum 替换，其余卷积仍由 DeepMD 执行。

DPA4 的一般数据流由 DeepMD-kit 负责：坐标、类型与邻居图 → 边几何和径向特征 → SeZM 交互块与读出 → 原子能量及总能量；力和 virial 由模型导数得到。该模型图不是本仓库重新实现的内核清单。

DeepMD

接入 DPA4 模型

DPA4Model 是 DeepMD DeepPot 的薄适配层，不复制模型图。不带 fused= 时它只是透传；带 fused= 时通过 model.fused_deepmd 把融合分段算子绑进 DeepMD 自己的分派接缝，并保留逐调用回退。

调用方式

from model import DPA4Model

# DeepMD baseline：不绑定任何算子
with DPA4Model("water.pt") as model:
    energy, force, virial = model.eval(coords, cells, atom_types)

# 绑定融合接缝（softmax / envelope），报告命中与回退
with DPA4Model("water.pt", fused=True) as fused:
    energy, force, virial = fused.eval(coords, cells, atom_types)
    print(fused.fused_ops)

先安装 DeepMD-kit，并让项目的 python/ 目录可导入。融合接缝需要 HIP 扩展和受支持的 DCU；没有扩展时 deepmd_patch 什么都不绑，bound_*=false，这次运行就等于 DeepMD baseline —— 不会留下"半个补丁"的状态。

选择规则

fused=True 装全部接缝；fused=("softmax",) / fused=("envelope",) 只装一个；也可以传 {"softmax": True, "envelope": False}。SFPG（source gate 非空）的 softmax 与非 fp32 输入会回退原实现并计入 *_fallbacks。

旧的 native_ops（GIE / RMSNorm patcher，只支持带 _dpmodel 的 pt_expt 模型）与 tilelang_ops 都已删除，传旧参数会显式报错。SO(2) 的 destination reduction 由 fused=("envelope",) 的 segment_sum 提供，不替换完整卷积。

其余图构建、旋转、radial mixing、SO(2) mixing stack、通用线性层与 fitting 仍由 DeepMD/PyTorch 执行；力/维里仍在 autograd 图内装配。细节见 融合算子接入方式。
