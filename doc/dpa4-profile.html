01 / Execution

选择运行路径

Direct · one HCU

独立测试原始 DeepMD

NPZ / geometry → deepmd.infer.DeepPot.eval → torch.profiler

不启动 LAMMPS。已附带 4,500 原子的 water_spce_4500.npz（O=0，H=1）。输入是 NPZ（coords、atom_types、cells）或当前几何读取器支持的正交盒几何；模型由 DeepMD 加载。可用 generate-data 从真实周期结构扩胞后生成可复用 NPZ。

python tests/deepmd/profile/test_dpa4_inference_profile.py dpa4 \
  --model-file /models/water.pt \
  --input-npz tests/deepmd/profile/water_spce_4500.npz \
  --device cuda:0 --memory-fraction 0.70 \
  --output-dir /tmp/profile-deepmd

始终调用原始 DeepPot，不加载本仓库 native 算子。支持 DeepMD 自动选择的 pt/pt_expt 等后端。附带水输入按 metadata 的 O,H 顺序重映射到模型元素编号；可用 --input-type-map O,H 显式指定。输出包含 Chrome trace 与热点 summary。

LAMMPS · one rank per HCU

使用 LAMMPS 模拟

LAMMPS data + input template + .pt2 → lmp / MPI

此路径传入原生 LAMMPS data 文件和模板。--gpu-ids 中每个 ID 对应一个单机 rank；多个 ID 需 MPI 和 with-comm 模型。仓库模板 tests/deepmd/profile/dpa4_water_profile.template 对应水样例 O,H 类型顺序。

python tests/deepmd/profile/test_dpa4_inference_profile.py lammps \
  --model-file /models/water-with-comm.pt2 \
  --data-file ../lammps/examples/rdf-adf/data.spce \
  --lammps-input tests/deepmd/profile/dpa4_water_profile.template \
  --lammps-exe /opt/dtk/bin/lmp --mpi-exe mpirun \
  --gpu-ids 0,1,2 --world-size 3 --replicate 2,2,2 --steps 20 \
  --output-dir /tmp/profile-lammps

3 个 GPU ID 会启动 3 个 MPI rank；2,2,2 将 4,500 原子的样例扩为 36,000 原子。默认真实 MD 运行 20 步，跳过前 5 次模型调用后采集 10 次。水模板使用 300 K 初速、0.25 fs、NVE，并保留 SPC/E bond/angle 项。该样例 data 是 full-style LAMMPS 输入，应通过 --data-file 使用，不要当作直接路径的 --geometry。

03 / Original DeepMD profiling

原始 DeepMD 热点分析

三种场景均使用 DeepMD 自身的模型计算，当前测试入口不安装本仓库 native 补丁。

直接推理。 通过 DeepPot 自动选择 pt/pt_expt 等后端，按可用显存预算扩胞并预热，再采集一次完整 eval。

元素映射。 附带水样例通过同名 metadata 的 O,H 顺序映射到实际模型编号；多元素模型也可用 --input-type-map O,H 显式指定。

热点指标。 查看 kernel、CPU op 与通信事件；采集 wall time 含 profiler 开销，不作为推理延迟或加速比。

LAMMPS 路径。 使用原始导出模型。有限窗口 profiler 需要 DeepMD C++ 采集支持；该支持不替换计算算子。
