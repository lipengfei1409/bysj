01 / Execution

选择运行路径

Direct · one HCU

独立测试 DPA4Model

NPZ / geometry → DPA4Model.eval → torch.profiler

不启动 LAMMPS。输入是 NPZ（coords、atom_types、cells）或当前几何读取器支持的正交盒几何；模型由 DeepMD 加载。可用 generate-data 从真实周期结构扩胞后生成可复用 NPZ。

python tests/deepmd/test_dpa4_inference_profile.py dpa4 \
  --model-file /models/water_pt_expt.pt \
  --input-npz /systems/water.npz \
  --device cuda:0 --max-atoms 8192 \
  --output-dir /tmp/profile-native

未传 --native-ops 时默认启用 GIE 与 RMSNorm；可用 --native-ops so2_envelope_reduce 单独测 attention-free SO2Convolution 的 destination reduction；比较 DeepMD baseline 时传 --native-ops ""。输出包含 Chrome trace 和 JSON summary；--max-atoms 是上限，需检查 summary 的实际 atom_count。

LAMMPS · one rank per HCU

使用 LAMMPS 模拟

LAMMPS data + input template + .pt2 → lmp / MPI

此路径传入原生 LAMMPS data 文件和模板。--gpu-ids 中每个 ID 对应一个单机 rank；多个 ID 需 MPI 和 with-comm 模型。仓库模板 tests/deepmd/dpa4_water_profile.template 对应水样例 O,H 类型顺序。

python tests/deepmd/test_dpa4_inference_profile.py lammps \
  --model-file /models/water-with-comm.pt2 \
  --data-file /path/to/lammps/examples/rdf-adf/data.spce \
  --lammps-input tests/deepmd/dpa4_water_profile.template \
  --lammps-exe /opt/dtk/bin/lmp --mpi-exe mpirun \
  --gpu-ids 0,1,2 --replicate 2,2,2 --steps 0 \
  --output-dir /tmp/profile-lammps

3 个 GPU ID 会启动 3 个 MPI rank；2,2,2 将 4,500 原子的样例扩为 36,000 原子。默认 --steps 0；增加 steps 时模板还会计算 SPC/E bond/angle 项。该样例 data 是 full-style LAMMPS 输入，应通过 --data-file 使用，不要当作直接路径的 --geometry。

输入和输出不能混用

路径必需输入扩胞方式profile 产物

直接推理的 generate-data 输出是 NPZ，不是 LAMMPS read_data 文件。多卡 LAMMPS 运行要求单机每 rank 一个可见 GPU 和包含 with-comm 路径的模型；水样例要求 model type map 为 O,H。

03 / Native operator validation

先验算子正确性，再测完整模型

不要只比较 profile 时间。保持输入、模型类型映射、实际 atom_count、设备和运行条件一致，并分别验证 primitive 与 energy/force/virial。

单算子 parity。 在支持的 DCU 上运行 GIE 与 RMSNorm 原生算子测试，对照 PyTorch/reference 输出，并检查反向梯度。

完整 DPA4 correctness。 对相同 NPZ 和 eager pt_expt .pt 模型，比较 native_ops=() baseline、GIE-only、RMSNorm-only 与默认组合的 energy、force、virial；只有 attention-free 模型才会使用可选的 SO(2) envelope reduction。

直接 profile 对照。 使用相同 --input-npz、--max-atoms、设备和内存参数；检查 JSON summary 中的 native_ops 与 native_ops_patched，再比较 device time、总 wall time 和显存。模型需是 eager pt_expt，并多次运行报告中位数。

LAMMPS 路径。 原生补丁只能在 eager DeepMD 模型加载后安装；已导出的 .pt2/.pte 无法加载后 patch。LAMMPS profile 路径继续使用 DeepMD 导出 artifact，不代表 DPA4Model 的 native patch 路径。

适配器默认只替换 plain RMSNorm 与受支持的 GIE scatter；`so2_envelope_reduce` 仅替换 attention-free SO2Convolution 的 destination reduction，不是完整 SO(2) convolution。缺少 HIP/DCU 扩展、受支持设备或目标模块会明确失败。传 native_ops=() 才会运行 DeepMD baseline。TileLang 算子包仍可独立使用，但此适配器不启用它。
