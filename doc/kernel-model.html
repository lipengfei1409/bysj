内核与模型

本仓库提供 RMSNorm/GIE 原生算子与独立 TileLang 内核；DPA4Model 默认用原生算子替换 GIE/RMSNorm，适配器不启用 TileLang。DPA4/SeZM 完整 descriptor、interaction、fitting 和能量/力/virial 路径由 DeepMD-kit 实现。下方源码映射对应相邻 deepmd-kit checkout 的 DPA4 实现。

Native primitives

RMSNorm + GIE

RMSNorm / zonal_scatter → kernels._C → HIP

当前本地 HIP 扩展默认编译 RMSNorm 与 GIE；完整 SeZM descriptor/interaction/fitting 由 DeepMD-kit 管理。

DPA4 / SeZM inference

DeepMD adapter

DPA4Model → DeepPot → DeepMD pt_expt → native GIE/RMSNorm

模型图、邻居图、能量和导数由 DeepMD-kit 执行；适配器默认仅将受支持的 GIE 和 plain RMSNorm 阶段替换为原生 HIP/DCU 算子。TileLang 不参与该路径。

DPA4 的一般数据流由 DeepMD-kit 负责：坐标、类型与邻居图 → 边几何和径向特征 → SeZM 交互块与读出 → 原子能量及总能量；力和 virial 由模型导数得到。该模型图不是本仓库重新实现的内核清单。

DeepMD pt_expt

接入 DPA4 模型

DPA4Model 是 DeepMD DeepPot 的薄适配层，不复制模型图。默认在 eager pt_expt 模型构造后 patch 当前模型实例的 GIE 与 RMSNorm；适配器不调用 TileLang，也不修改相关环境变量。

调用方式

from model import DPA4Model

# Default: native HIP/DCU GIE + RMSNorm patches.
with DPA4Model("water_pt_expt.pt") as model:
    energy, force, virial = model.eval(coords, cells, atom_types)

# Explicit DeepMD baseline:
with DPA4Model("water_pt_expt.pt", native_ops=()) as baseline:
    energy, force, virial = baseline.eval(coords, cells, atom_types)

先安装 DeepMD-kit，并让项目的 python/ 目录可导入。原生 patch 要求 HIP 扩展和受支持的 DCU，以及可访问 deep_eval._dpmodel 的 eager pt_expt .pt 模型；其他模型需显式传 native_ops=() 使用 DeepMD baseline。

选择规则

native_ops=None 默认选择 ("gie", "rmsnorm")；传入 native_ops=() 明确运行 DeepMD baseline，也可只选择一个原生算子。旧 tilelang_ops 参数仅为兼容保留，非空值会被拒绝；DPA4 TileLang dispatch 已从对应 DeepMD-kit checkout 移除。

原生 patch 需要 eager pt_expt .pt 模型和受支持的 HIP/DCU。缺失扩展、后端或目标模块会报错并关闭已加载模型；单次输入不满足原生算子条件时则调用原始 DeepMD 方法。旧 pt、导出的 .pt2/.pte 不支持加载后 patch；导出 artifact 已固定的算子图也不会被 native_ops=() 改写。独立 TileLang 算子仍保留在项目中，不由此适配器调用。

只替换 plain RMSNorm 和受支持的 GIE scatter 阶段；其余图构建、通用线性层、拟合等仍由 DeepMD/PyTorch 执行。当前 native wrapper 面向 float32 HIP/DCU 推理。
