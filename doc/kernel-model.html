DPA4 / SeZM inference

DeepMD adapter

DPA4Model → DeepPot → DeepMD pt_expt → 可选 TileLang 算子

模型图、邻居图、能量和导数由 DeepMD-kit 执行；本项目只替换显式选择且受支持的独立算子阶段。

DPA4 的一般数据流由 DeepMD-kit 负责：坐标、类型与邻居图 → 边几何和径向特征 → SeZM 交互块与读出 → 原子能量及总能量；力和 virial 由模型导数得到。该模型图不是本仓库重新实现的内核清单。

DeepMD pt_expt

接入 DPA4 模型

DPA4Model 是 DeepMD DeepPot 的薄适配层，不复制模型图。选择的环境 gate 在 DeepMD 构建 descriptor 时生效。

调用方式

from model import DPA4Model

with DPA4Model(
    "water_pt_expt.pt",
    tilelang_ops=("radial_basis", "edge_geometry"),
) as model:
    energy, force, virial = model.eval(coords, cells, atom_types)

先安装 DeepMD-kit，并让项目的 python/ 目录可导入。显式 selector 会映射为 DP_TILELANG_* gate，只在模型构建期间设置，随后恢复原环境。

选择规则

tilelang_ops=None 保留调用者现有环境；tilelang_ops=() 强制 DeepMD baseline；传入别名则只开启对应算子。

运行时 TileLang dispatch 要求 eager pt_expt 后端。旧 pt checkpoint 可运行 baseline，但不支持这些 TileLang dispatch。.pt2/.pte 的算子选择已在导出时固定，不能加载后再切换。

未选择的图构建、通用线性层、拟合等仍由 DeepMD/PyTorch 执行；被选算子遇到不支持的模式或设备会报错，不静默回退。该 opt-in 路径面向 float32 HIP/DCU 推理；训练、MPI exchange、spin/bridging 和 stress/virial 不在当前 TileLang 范围内。
